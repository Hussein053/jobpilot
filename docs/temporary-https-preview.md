# Temporary HTTPS DRY_RUN preview

The preview workflow runs only for owner-repository pull requests from the reviewed branches `feat/dry-run-mvp-reviewed` and `feat/preparation-answer-history` while the repository remains public. It uses a standard runner in this public repository, a fresh synthetic PostgreSQL service and a free Cloudflare Quick Tunnel. It does not provision paid infrastructure, use production credentials, migrate production, modify live n8n workflows or enable applications. The ordinary CI workflow remains separate and can complete while the preview stays available.

The tunnel points to a fixed loopback gateway, with frontend and API on one HTTPS origin. Before the gateway accepts requests, the workflow creates synthetic fixtures while the API is private, restarts the API in production mode, verifies its immutable DRY_RUN policy, builds and starts the production Next.js server, then verifies the full flow over the assigned HTTPS URL. Browser session cookies must be Secure, HttpOnly and SameSite=Lax. Account provisioning, email/password reset, credential storage, external sign-in and integration writes are blocked at the preview gateway. Owned discovery reads remain authenticated. Anonymous access never supplies a session or bypasses normal password sign-in.

A public release digest verifies the official Cloudflare tunnel binary. The gateway accepts only the assigned `https://*.trycloudflare.com` origin, rejects cross-origin mutations and encoded paths, fixes its upstreams to loopback, prevents private-page caching and indexing, and fails closed on invalid or expired state. The terminal host never starts. Real employer browsing and final submission remain disabled.

The available URL and expiry are in the `synthetic-https-preview` workflow artifact and an authenticated workflow update to the owning PR description. A hidden machine-readable PR marker also contains the encrypted fixture access, so short-lived artifact download links are not required. Only the dedicated publication step receives a PR-write token; app servers do not. The encrypted access binds its URL, expiry and source commit for validation when decrypted. That artifact includes a successful browser report and synthetic screenshots. Login credentials are RSA-OAEP encrypted using the committed public key; its matching private key stays in the operator's ignored `.tmp/jobpilot-preview/` directory and never enters GitHub. The artifact never contains the plaintext credential file, database master key or live sessions. Decrypt `access.enc` locally with `openssl pkeyutl -decrypt -inkey .tmp/jobpilot-preview/access-private.pem -pkeyopt rsa_padding_mode:oaep -pkeyopt rsa_oaep_md:sha256 -in access.enc -out .tmp/jobpilot-preview/access.json`, then keep that result private. This is a fixture account, not an applicant's real credentials.

The preview expires four hours after startup; the gateway returns 410 after expiry and the job's isolated runner cleanup stops its processes. A new source update cancels the old preview. Quick Tunnels have no uptime SLA and do not reliably support SSE; this is not permanent hosting or production. Read/write form actions use ordinary HTTP and have browser verification. Physical iPhone Add to Home Screen still requires a device check; HTTPS, manifest, icons, service worker and 390×844 layout are checked automatically.

To renew, rerun the preview workflow job on the reviewed commit. For permanent access, choose an approved HTTPS hosting environment, persistent database/storage and managed secrets, then request any production or paid-service authorization separately. Do not paste passwords, applicant data or API credentials into this synthetic preview.

New answer-history previews additionally verify explicit private value reveal and unmounting when closed. Encrypted used-answer copies remain immutable; deleting a reusable Information Bank answer does not delete those copies. Their purpose and retention are described in docs/application-preparation.md. Older reference-only simulations remain readable without fabricated values.
